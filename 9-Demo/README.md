## Suggested Demo Flow

1. Start the application.
2. Show login/authentication.
3. Show administrator access.
4. Create/view/update a student record.
5. Create/view/update a room.
6. Show room capacity/occupancy.
7. Perform a valid room allocation.
8. Demonstrate a rejected full-room or duplicate allocation.
9. Modify/deallocate an allocation.
10. Log in as a student and show own allocation information.
11. Demonstrate authorization/isolation if implemented.
12. Show the final relevant output.

Record only behavior that actually exists in the implementation.
